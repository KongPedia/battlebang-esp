# Decision ownership

Existing firmware architecture rationale remains in [product/library owner documentation](../../firmware/README.md),
[engineering criteria](../../.agents/references/engineering.md) and Git/PR history. This index does not claim the
repository has no decisions or move current rationale into a second source of truth.

Record a new consequential cross-cutting decision here only when existing owner conventions do not provide a better
home. Common's `domain-modeling` and optional `ADR-FORMAT.md` can help when needed; they do not require an ADR per task,
new domain layers or copying generic forms. Behavioral acceptance follows [specification ownership](../specs/README.md).
